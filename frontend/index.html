Download a shared folder

Paste a public OneDrive or SharePoint folder link. We’ll fetch its files and return one ZIP.

How it works

Why do I need a public link?
The tool downloads files without requiring an account. If a link asks for a sign-in, the tool cannot access it.

How long does it take?
It depends on the folder size. Small folders are nearly instant; large ones can take several minutes.

Is my data safe?
The server creates a temporary ZIP and deletes it immediately after the download finishes. No files are stored permanently.

Only links that open without signing in are supported. Large folders can take a few minutes; keep this tab open while the ZIP is prepared.
